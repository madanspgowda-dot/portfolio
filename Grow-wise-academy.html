WEB DEVELOPMENT PROJECT

GROW WISE ACADEMY

Digital Learning & Study Resources Platform

Grow Wise Academy is an educational web application designed to support students in their learning. It provides textbooks, study materials and educational videos to help students improve their knowledge. Students can also find contact information and share their opinions through the feedback option. The frontend is developed using HTML, CSS and JavaScript, while PHP is used for backend development. XAMPP is used as the local development environment.

Project Overview

Introduction and development details of Grow Wise Academy.

Project Name: Grow Wise Academy

Project Type: Educational Web Application

Frontend: HTML, CSS and JavaScript

Backend: PHP

Local Development Environment: XAMPP

The purpose of Grow Wise Academy is to make useful learning resources accessible to students in one place. The application provides textbooks and study materials, along with educational videos that help students enhance their knowledge. It also includes contact details so students can get in touch, and a feedback option where they can share their suggestions or experience.

Main Application Features

  • Textbooks and study materials for students.
  • Educational videos to support learning.
  • Contact details for communication.
  • Feedback option for students.

Technology Stack

Languages and tools used to develop the project.

1. HTML

HTML creates the structure of the website, including headings, forms, links, images and page sections.

2. CSS

CSS styles the website, arranges page elements, manages layouts and makes the interface visually appealing and responsive.

3. JavaScript

JavaScript adds client-side behaviour and interactive features to the website.

4. PHP

PHP handles server-side programming and backend functionality, processing information sent from the website interface.

5. XAMPP

XAMPP provides a local server environment for running and testing the PHP-based website during development.

Note: XAMPP is a local server package. It can provide database services through its bundled MariaDB server.

Development Process

How the frontend and backend parts work together.

01 · Frontend

HTML creates the page structure, CSS styles the interface, and JavaScript adds interactive behaviour.

02 · Backend

PHP handles server-side operations and processes information sent from the website interface.

03 · Local Testing

XAMPP is used to run the PHP project locally and test the website during development.
